1. **确认现场与控制者。** 查明确会话终态、进程和新截图。最后是游戏重连页，未点击退出、未重启、未改网络/权限/凭据。先确认页面真正恢复，不能沿用旧战斗截图。
2. **核对版本。** 检查本地与 f1 的 HEAD/工作区，保留独立改动；需要同步时只快进已验证提交。运行修复为 `67aa705`、`6d3dabe`、`9f85e1b`。
3. **让程序继续。** 新帧确认仍是该战斗时，使用既有冒险入口衔接战斗与后续奖励/地图，不注入旧中局参数。若已经到地图/奖励/登录，则按新场景处理。记录 run_id，有界、增量读取状态与事件。
4. **按新证据诊断。** 不能将日志里的身份当作独立证明；同时核对卡面、费用徽章归属与实际输入。未知牌允许跳过；奈德麗形态选择尚未实现，不能猜目标或手动点牌绕过验收。
5. **记录结果。** `battle_end` 不独立证明获胜，最终页不证明全程无人介入；本冒险已经历开发恢复，完整无人值守验收另行安排。
