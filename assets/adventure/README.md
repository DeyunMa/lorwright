# 冒险画面模板

全部模板裁自 `tests/fixtures/mapnav/` 的 1920×1080 截图：
地图返回键和缩放控件来自 `1080p_zoommax.png`；旅行、战斗、敌方能力标题
和已完成面板分别来自 `1080p_node_panel.png`、`1080p_battle_detail.png`、
`1080p_panel.png`。能力标题、名称和品质来自 `1080p_ability_select.png`。
地图缩放控件只匹配内部，并检查加减号亮度；另用 f1 辅助英雄选择后的
地图帧和退出确认框验证，不能据此保证其他遮挡与地图状态均能识别。

能力名称表仅覆盖这张截图中可核实的三个名称；品质由截图文字识别，
无法识别任何一个候选或品质时不做选择。尚无点击候选后的连续截图，
因此当前只输出推荐并保存快照，不点击或确认奖励。

战斗卡牌奖励的模板、槽位与 `reward_digits/` 字形采自
`tests/fixtures/card_rewards/before.png`；选中框和按钮启用状态用
`selected-left.png` 校验。`card_rewards.json` 当前只覆盖截图里的三张
卡和三件附带道具，费用字形只覆盖实测的 1、3；其他卡、道具或费用
读取不全则停止，不代表已经覆盖所有奖励。

卡牌品质与道具品质分开：`03PZ018` 普羅大砲的普通品质和
`05BW003T1` 排山倒海的 `None` 品质来自 Riot Data Dragon 7.11.0 的
set3/set5 官方卡牌数据；`99PZ113` 生物編目員的 Rare 来自
`lorwright-artifacts/research/lorwright-pack/data/cards.jsonl` 客户端
静态数据。`unranked` 表示已核实的 `None`，默认排序放在普通之下；
缺失或未知品质不能冒充 `unranked`。三个道具的「稀有」文字是
道具品质，不用于替代卡牌品质。光輝板甲写有费用 +1，但截图显示
的仍是原费用，应用时机未实测，因此同品质比较费用涉及该道具时弃权。

奖励自动选择只经过上述连续截图离线回放；选中其他槽位、其他分辨率、
动画与新奖励尚未实机验收。

辅助英雄标题、副标题来自 `screens/1080p_jinx_support_selection.jpg`；
选择按钮模板分别来自 `support/m3-supp1.jpg`（960×540 放大到设计尺寸）
和 f1 原生 1080p 左组选中帧。`support_digits/` 是 1080p 和历史 960×540
页面中截取的 0–6 字形；选中前后有历史中间组与 f1 左组的实拍画面，
右组选中尚无实机依据。显示为 0 的费用可能随法力变化，需参与比较时按未知处理；
7–10 缺真实样本，合成拒绝测试不证明覆盖所有未知字形。
排序使用页面显示费用；附带道具是否改变实际费用仍需逐项验证。
