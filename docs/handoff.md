# 接手入口

Jinx 每周冒险已在 f1 核对 3/3，过程中有开发修复和中途恢复。合并后的跨冒险泛化有离线证据，仍待实机验收。当前能力和会话证据见[阶段状态](status.md)。

## 接手顺序

1. 在仓库根目录安装开发依赖，运行 `python tools/test_data.py` 准备库外基线图片。图片位置、恢复和维护方式见[项目目录与图片](layout.md)。
2. 按改动范围跑回归。研究三个周常的共用视觉问题时，用相同输入比较两个版本的逐图结果。方法见[离线验收](offline-validation.md)。
3. 下次获准实机验证时，先核对 f1 的版本、工作区、会话锁和实时画面。最后记录是 `cb985b6`，当时停在每周列表。同步后的验收用目标运行路径的事件及结果。自动化回归在同步前的开发环境完成。命令与环境见 [CLI](cli.md) 和 [f1 运维](../tools/f1/)。
