## 3. 这套牌怎么赢（决策要点）

蜘蛛快攻的核心不是单卡质量，是**铺场速度 + 蛛灵数量**。

| 要点 | 对决策层的影响 |
|---|---|
| 场上限 6 个单位 | 满员后不能再铺，出牌阶段要转向 buff / 直伤 |
| 蛛灵（Spiderling）是 1/1 token | 便宜、可牺牲 → 格挡时优先拿蛛灵去换 |
| 快攻要抢血 | 攻击声明的 `nexus_weight` 调高（当前默认 3.0，快攻可以到 4–5） |
| 单位不会因攻击力竭 | LoR 里攻击几乎无成本 → **有令牌就默认全员进攻**，只在白送时才留人 |
| 法力不结转 | 每回合尽量花光，没有「存法力」这个策略 |

## 4. 必须记住的 LoR 机制（容易搞错的）

1. **不是「回合制」，是交替优先权**。大蓝按钮 = 我持有优先权。
   按钮文字「結束回合」= 按下即结束本轮；「略過」= 只是把优先权交给对手。
2. **攻方不能指定打谁**。攻方声明攻击者 → 守方分配格挡者。
   唯一例外是**挑战者（Challenger）**。
3. **法力不结转**，回合结束清空。
4. **场上限 6 单位**（双方各自 6）。
5. **攻击令牌**决定本轮谁先攻；有令牌才能声明攻击者。
6. 关键词：灵巧（只能被灵巧挡）、恐惧（只能被 ≥3 攻挡）、碾压（溢出穿脸）、
   快速攻击（先手击杀则不吃反伤）、坚韧（受伤 −1）、挑战者（攻方选格挡者）。
