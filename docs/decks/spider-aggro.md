## 3. 伊莉絲升级：这套牌的核心开关

| | 等级 1 | 等级 2（蜘蛛女王伊莉絲） |
|---|---|---|
| 数值 | 2 费 2/3 | 2 费 **4/3** |
| 关键词 | 恐惧 | 恐惧 + **挑战者** |
| 效果 | 攻击：召唤 1 只攻击中的小蜘蛛 | **我方其他蜘蛛获得挑战者与恐惧** |

**升级条件**：回合开始，场上有 3 只以上其他蜘蛛。

这套牌有 9 张蜘蛛单位、倾巢而出一次给 3 只小蜘蛛 —— **几乎每局第 3–4 回合就能升级**。

升级后的影响是决定性的：

- **所有蜘蛛获得挑战者** → 攻击时由我指定谁挡谁，而不是对手分配格挡
- **所有蜘蛛获得恐惧** → 小蜘蛛也变成「只能被 ≥3 攻格挡」

→ 这就是为什么战斗求解器必须支持 `challenger` 和 `stunned`，否则升级后整套决策全错。

## 5. 这套牌怎么打

### 5.1 核心是 buff 叠乘，不是单卡质量

| 来源 | 加成 | 持续 |
|---|---|---|
| 群蛛之主（5 费） | 其他蜘蛛 +2\|+0 | **永久** |
| 尖嘯蜘蛛（4 费） | 攻击时全体蜘蛛 +2\|+0 | 本回合 |
| 發狂疾行蛛（3 费） | 召唤时其他蜘蛛 +1\|+0，敌军 −1\|−0 | 本回合 |
| 傾巢而出（6 费） | 召唤 3 只小蜘蛛，全体蜘蛛 +1\|+0 | 永久 |
| 1★ 蜘蛛女王 | 每次攻击给小蜘蛛 +1\|+0 | 永久 |

→ **出牌顺序 > 出哪张牌**。同一回合里，先出「给 buff 的」再出「吃 buff 的」，
战力差距可以到一倍。

### 5.2 恐惧是主要穿透手段

伊莉絲、蜘術士、發狂疾行蛛 天生带恐惧；升级后全体带恐惧。
对手场上如果全是 2 攻单位，**一只恐惧单位就是 5 点打脸**。

### 5.3 击晕是唯一的控场

蜘蛛哨兵、蜘術士能击晕。击晕的敌人**本回合不能攻击也不能格挡**。
对手有大单位时，击晕它再全力进攻，等于白拿一回合。

### 5.4 没有的东西（很重要）

| 没有 | 后果 |
|---|---|
| 直伤法术 | **「法术补刀」这条规则在这套牌里不存在**，删掉 |
| 抽牌 | 手牌只减不增，打完就是打完 |
| 治疗 | 水晶血量只降不升 |
| 群体解场 | 只能靠交换和击晕 |

## 6. 对 L1 / L2 的直接影响

| 结论 | 说明 |
|---|---|
| **删除 R6「法术补刀」** | 牌组里没有直伤法术，这条规则永远不会触发 |
| **`stunned` 必须进 state** | 击晕改变格挡合法性，求解器算错就是送人头 |
| **`challenger` 必须建模** | 伊莉絲升级后全体挑战者，攻击声明从「守方选」变成「攻方选」 |
| **新增「buff 优先」出牌顺序规则** | 确定性可判定：同回合内先出给 buff 的牌 |
| **`nexus_weight` 调高** | 快攻 + 恐惧穿透，脸伤比换血值钱。建议 4.0（默认 3.0） |
| **出牌顺序的深度权衡交给 L2** | 「群蛛之主 vs 尖嘯蜘蛛 先出哪个」需要算两层，是 JEV 的地盘 |

### 出牌评分（草稿，待实战校准）

```
score(card) =
    base = atk + hp
  + 群蛛之主：+ 2 × (场上蜘蛛数 − 1)      # 每多喂一只就多赚 2 攻
  + 尖嘯蜘蛛：+ 2 × (场上蜘蛛数)           # 本回合攻击前出，等于全体 +2
  + 發狂疾行蛛：+ 1 × (场上蜘蛛数) + 1     # 顺带削对面 1 攻
  + 傾巢而出：+ 3（三只小蜘蛛）+ 1 × (场上蜘蛛数)
  + 蜘蛛哨兵 / 蜘術士：+ 2 × (对面最大攻击力 − 3)  # 击晕大单位才值
  − cost × 1.5
```

> 这套公式里「场上蜘蛛数」是唯一真正需要 state 的变量，比 v1 的
> `atk*2 + hp - cost*1.5` 贴近这套牌的实际收益结构。
