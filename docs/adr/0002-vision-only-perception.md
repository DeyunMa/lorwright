# ADR-0002：英雄之路只能走纯视觉

- 状态：**Accepted**
- 日期：2026-11-02

## 背景

最初设想用 Riot 客户端的本地 API（`localhost:21337`）读对局状态，
API 直接给出卡牌、坐标、法力，比图像识别可靠得多。

但目标模式是**英雄之路（Path of Champions）**。

## 事实

Riot 官方仓库的 issue（`RiotGames/developer-relations#773`）：

> "There are currently no APIs for Path of Champions mode."

该 issue 于 2023-05-28 提出，至今 **open**，未实现。

官方文档也只说明 21337 覆盖：收藏、构筑器、**进行中的 PvP 对局**。

## 决策

**感知层放弃 API，改为纯视觉：**

```
截图（mss） → 模板匹配（OpenCV）/ OCR（RapidOCR） → 状态
```

## 后果

| 影响 | 说明 |
|---|---|
| 可靠性下降 | 认错牌、认错数字的风险由图像质量决定 |
| 工程量大增 | 需要卡牌图库、按钮模板、坐标标定 |
| 硬约束 | 必须 1080p 全屏 + 100% 缩放，否则坐标全错 |
| 可移植性 | 换分辨率/语言要重新采集素材 |

## 备选方案（已否决）

| 方案 | 否决原因 |
|---|---|
| 改做 PvP | 用户目标是 PoC 周本 |
| 读写游戏内存 | 违反 ToS，且不稳定 |
| 只用 VLM 直读 | 每步 1–3s，一局 10–20 分钟，太慢 |

## 缓解

- 规则层覆盖 70–80%，减少对视觉的依赖频率
- VLM 只做兜底，不进入主循环
- 出错自动截图存档，便于迭代模板
