# L1 规则层：蜘蛛快攻

**定位**：确定性决策，覆盖 70–80% 的回合。
**原则**：纯函数（只读 state，返回 Action），可单测，不碰网络/截图/文件。

代码：`src/lorwright/decide/rules.py::SpiderAggroPolicy`

---

## 一、前置守卫

```
if state.ui_state != MY_TURN_IDLE: 弃权
```

**不是我的回合，一律不动。** 这条规则优先级高于一切——
2026-11-02 的教训：状态不明时盲点，机器人点进了设定菜单。

## 二、需要的状态字段

规则再漂亮，字段解析不出来就是空转。下表是 L1 的硬依赖（对应 issue #4）：

| 字段 | 类型 | 来源 | 用途 |
|---|---|---|---|
| `ui_state` | 枚举 | 颜色探针 | 守卫 |
| `mana` / `max_mana` | int | 右侧法力数字 | 可出牌判定 |
| `spell_mana` | int | 右侧法术槽 | 法术可出判定 |
| `hand[]` | 列表 | 手牌区识别 | 出牌候选 |
| `hand[].cost` | int | 卡面左上数字 | 费用过滤 |
| `hand[].kind` | 单位/法术 | 卡面边框颜色 | 分流 |
| `my_units[]` | 列表 | 我方场面 | 攻击力计算 |
| `enemy_units[]` | 列表 | 敌方场面 | 威胁评估 |
| `my_units[].can_attack` | bool | 攻击令牌 + 未行动 | 攻击候选 |
| `nexus_hp` / `enemy_nexus_hp` | int | 左右水晶旁数字 | 斩杀/保命 |
| `has_attack_token` | bool | 右下剑盾图标 | 是否轮到我攻击 |

**没有这些字段，L1 只能做 R7（空手结束回合）。**

## 三、规则表

按优先级从高到低，**第一条命中的直接返回**。

| # | 名称 | 条件 | 动作 | 触发频率 |
|---|---|---|---|---|
| **R1** | 斩杀 | `sum(atk of can_attack) >= enemy_nexus_hp` | `ATTACK nexus` | 低（但决定性） |
| **R2** | 保命 | `sum(enemy atk) >= nexus_hp` 且我方有单位可挡 | `ATTACK 最大威胁单位` | 低 |
| **R3** | 铺场 | 有单位牌可出 且 `len(my_units) < 6` | `PLAY_CARD 最高性价比单位` | **高** |
| **R4** | 优势交换 | 敌方有 `atk >= 3` 单位 且 我方有能 1 换 1 的 | `ATTACK 该单位` | 中 |
| **R5** | 抢血 | `has_attack_token` 且 我方总攻 > 敌方场面总血 | `ATTACK nexus` | **高** |
| **R6** | 法术补刀 | 有伤害法术且能击杀敌方单位 | `PLAY_CARD 该法术` | 中 |
| **R7** | 空手 | 无任何可出牌 | `END_TURN` | **高** |
| **R8** | 存法力 | `mana <= 1` 且 无 1 费牌 | `END_TURN` | 低 |

### R3「最高性价比」怎么算

蜘蛛快攻的核心是**铺场速度**，不是单卡质量。所以：

```
score(card) = card.atk * 2 + card.hp - card.cost * 1.5
```

攻击力权重高（快攻要打脸），费用惩罚中（同等强度下更便宜的先出）。

**同分时**：优先有「挑战」（Challenger）的，其次费用低的。

## 四、弃权条件（交给 L2）

规则**故意**不处理的局面：

| 场景 | 为什么规则处理不了 |
|---|---|
| 多张同费牌价值接近 | `score` 差值 < 1 时，规则无法区分 |
| 双方场面都 ≥ 3 单位 | 交换顺序影响结果，需要搜索 |
| 需要预判对手响应 | 规则看不到对手手牌/法力 |
| 法术该现在打还是留着 | 时机判断，非局部信息 |

**弃权不是失败**——弃权率是 L1 的健康指标。目标：**20–30% 弃权**。
低于 10% 说明规则太激进（容易错），高于 40% 说明规则太保守（L2 压力大）。

## 六、为什么这样分层

| 层 | 决策类型 | 延迟 | 成本 | 覆盖目标 |
|---|---|---|---|---|
| L1 规则 | 确定性 | <1ms | 0 | 70–80% |
| L2 JEV | 有界选择 | 100–500ms | 低 | 15–25% |
| L3 LLM | 开放推理 | 2–20s | 高 | 1–5% |

**规则先吃掉简单的，JEV 只处理"选哪个"的模糊地带，LLM 只在都弃权时兜底。**
这样 95% 的回合不需要联网。
