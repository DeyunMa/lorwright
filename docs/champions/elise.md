## 3. 伊莉絲升级：这套牌的核心开关

| | 等级 1 | 等级 2（蜘蛛女王伊莉絲） |
|---|---|---|
| 数值 | 2 费 2/3 | 2 费 **4/3** |
| 关键词 | 恐惧 | 恐惧 + **挑战者** |
| 效果 | 攻击：召唤 1 只攻击中的小蜘蛛 | **我方其他蜘蛛获得挑战者与恐惧** |

**升级条件**：回合开始，场上有 3 只以上其他蜘蛛。

这套牌有 9 张蜘蛛单位、倾巢而出一次给 3 只小蜘蛛 —— **几乎每局第 3–4 回合就能升级**。

升级后的影响是决定性的：

- **所有蜘蛛获得挑战者** → 攻击时由我指定谁挡谁，而不是对手分配格挡
- **所有蜘蛛获得恐惧** → 小蜘蛛也变成「只能被 ≥3 攻格挡」

→ 这就是为什么战斗求解器必须支持 `challenger` 和 `stunned`，否则升级后整套决策全错。

## 5. 这套牌怎么打

### 5.1 核心是 buff 叠乘，不是单卡质量

| 来源 | 加成 | 持续 |
|---|---|---|
| 群蛛之主（5 费） | 其他蜘蛛 +2\|+0 | **永久** |
| 尖嘯蜘蛛（4 费） | 攻击时全体蜘蛛 +2\|+0 | 本回合 |
| 發狂疾行蛛（3 费） | 召唤时其他蜘蛛 +1\|+0，敌军 −1\|−0 | 本回合 |
| 傾巢而出（6 费） | 召唤 3 只小蜘蛛，全体蜘蛛 +1\|+0 | 永久 |
| 1★ 蜘蛛女王 | 每次攻击给小蜘蛛 +1\|+0 | 永久 |

→ **出牌顺序 > 出哪张牌**。同一回合里，先出「给 buff 的」再出「吃 buff 的」，
战力差距可以到一倍。

### 5.2 恐惧是主要穿透手段

伊莉絲、蜘術士、發狂疾行蛛 天生带恐惧；升级后全体带恐惧。
对手场上如果全是 2 攻单位，**一只恐惧单位就是 5 点打脸**。

### 5.3 击晕是唯一的控场

蜘蛛哨兵、蜘術士能击晕。击晕的敌人**本回合不能攻击也不能格挡**。
对手有大单位时，击晕它再全力进攻，等于白拿一回合。

### 5.4 没有的东西（很重要）

| 没有 | 后果 |
|---|---|
| 直伤法术 | **「法术补刀」这条规则在这套牌里不存在**，删掉 |
| 抽牌 | 手牌只减不增，打完就是打完 |
| 治疗 | 水晶血量只降不升 |
| 群体解场 | 只能靠交换和击晕 |

## 6. 这套牌的 L1 规则（伊莉絲专属）

> 通用决策层设计在 `docs/decision-l1-rules.md`。
> 本節只写**因为这套牌而成立**的东西。
> 代码：`src/lorwright/champions/elise/policy.py`

### 6.1 决策顺序

```
P0 守卫（没优先权 → NO_OP）
  → P4 出牌（先 buff，再按评分）
  → P2 攻击声明（求解器算过才打）
  → 收尾 END_TURN
```

顺序不能反：LoR 里新出的单位**当回合就能攻击**（没有召唤失调），
所以先出牌再攻击永远比反过来强。

### 6.2 出牌评分

v1 的 `atk*2 + hp - cost*1.5` 把这套牌当纯快攻算，**是错的**。
这套牌的收益结构是 **buff 叠乘**：群蛛之主 +2|+0、尖嘯蜘蛛 +2|+0、
發狂疾行蛛 +1|+0，都是「喂给其他蜘蛛」的。所以评分必须含「场上蜘蛛数」。

```
score(card) =
    atk + hp
  + 群蛛之主     : + 2 × (场上蜘蛛数 − 1)      # 每多喂一只多赚 2 攻
  + 尖嘯蜘蛛     : + 2 × 场上蜘蛛数            # 攻击前出等于全体 +2
  + 發狂疾行蛛   : + 1 × 场上蜘蛛数 + 1        # 顺带削对面 1 攻
  + 傾巢而出     : + 3（三只小蜘蛛）+ 场上蜘蛛数
  + 蜘蛛哨兵/蜘術士 : + 2 × max(0, 对面最大攻击力 − 3)
  + 伊莉絲       : + 10（核心引擎，每次攻击都召唤，不是一次性）
  + 泰爾石       : + 3（灵活度）
  − cost × 1.5
```

### 6.3 buff 顺序（确定性规则）

**先铺场，再召唤「召喚此牌時」型 buff。** 这条 2026-11-04 更正过，之前写反了。

官方 Data Dragon `7_10_0` 的效果文本：

| 牌 | 代码 | 文本 | 顺序 |
|---|---|---|---|
| 群蛛之主 | `01NX023` | **召喚此牌時**，賦予我方其他蜘蛛單位 +2\|+0 | **后出** |
| 發狂疾行蛛 | `01SI056` | **召喚此牌時**，本回合給予我方其他蜘蛛單位 +1\|+0，並使所有敵軍單位 -1\|+0 | **后出** |
| 尖嘯蜘蛛 | `04NX016` | **攻擊：**本回合給予蜘蛛友軍單位 +2\|+0 | 与顺序无关 |
| 傾巢而出 | `01SI050` | 召喚 3 隻小蜘蛛，並賦予我方蜘蛛單位 +1\|+0 | 与顺序无关 |

前两条是「召喚此牌時」——只影响**当时已在场**的其他蜘蛛，先出它反而 buff 到更少的蜘蛛。
第三条是攻击时触发，第四条自己召唤的自己吃到，都跟出牌先后没关系。

**之前错在哪**：旧结论说「所有 buff 都是给其他蜘蛛的，先出只会让后面的牌更值」。
这句话只对「增强之后打出的牌」成立，这套牌里一张这种效果都没有。错把
「给已有的加」当成了「给后来的加」，于是 `BUFFER_EFFECTS` 里混进了四种效果，
排序写成 `sort(key=(not is_buffer, -score))`，反而让群蛛之主永远第一个出。

代码现在叫 `SETTLE_LAST_EFFECTS`，只含前两条；`rank_playable()` 用
`sort(key=(settles_last, -score))`，`False` 在前。

**依据**：`lorwright-artifacts/analysis/full-resource/starter-deck-reference.json`
（Data Dragon 7_10_0，九张牌的双语数据与效果文本）。

### 6.4 这套牌删掉了哪些通用规则

| 规则 | 结论 |
|---|---|
| 法术补刀 | **删掉**。牌组没有任何直伤法术，永远不会触发 |
| 存法力 | **不存在**。LoR 法力不结转，回合结束清空 |
| 优势交换「攻击某个单位」 | **不是合法动作**。只有带挑战者才能选格挡者 |

### 6.5 为什么 v1 的 8 条规则被推翻

| # | 结论 | 问题 |
|---|---|---|
| R1 斩杀 | ⚠️ 算错 | `sum(atk) >= 敌方血量` 忽略了**对手分配格挡** |
| R2 保命 | ❌ 动作不存在 | 对手攻击时你做的是**分配格挡**，不是攻击单位 |
| R3 铺场 | ✅ 合理 | 但评分要按 buff 叠乘重写 |
| R4 优势交换 | ❌ 动作不存在 | 同上；只有**挑战者**能选格挡者 |
| R5 抢血 | ⚠️ 条件错 | 攻击几乎无成本，快攻默认就该全员上 |
| R6 法术补刀 | ❌ 这套牌没有 | 没有直伤法术 |
| R7 空手 | ✅ 合理 | 定义改成「没有可打出的牌」 |
| R8 存法力 | ❌ 死规则 | LoR 法力不结转 |

**净结果：3 条硬错误、1 条死规则、2 条动作不存在。**
R1/R4/R5 已经合并成同一个「攻击声明求解器」——斩杀是它的副产品。

### 6.6 已知未建模（不阻塞，但会算偏）

| 未建模 | 影响 | 为什么先不做 |
|---|---|---|
| 尖嘯蜘蛛的「攻击时全体 +2\|+0」 | 攻击声明的脸伤会算少 | 「Spider allies」是否包含自身存在歧义，需实测 |
| 伊莉絲的「攻击：召唤小蜘蛛」 | 攻击收益会算少一只 1/1 | 同上 |
| 挑战者实际选哪个格挡者 | `chooser="attacker"` 已支持，但感知层还没解析 | 需要挑战者图标模板 |
| 泰爾石的三选一 | 开了就默认选 +2\|+2 | 需要选牌界面截图才能标定 |

这些都属于「算偏一点」，不会让机器人做出危险动作（比如误点菜单）。
先上真机跑通主循环，再回来补。
